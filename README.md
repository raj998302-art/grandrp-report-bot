# GrandRP ReportBot — Android

Auto-reply bot for **Grand RP Mobile** game administrators.

Answers player reports automatically while you are AFK/sleeping, and
auto-confirms handshake offers from other admins (anti-AFK test).

## How it works

- The app uses an **AccessibilityService** to read the on-screen game chat.
- Player reports look like: `19:53 Ryan_Itachi[440]: help [Num. of reports: 1]`
- The bot matches the report against rules (keywords → reply) and types the
  answer command (default `/ans {id} Greetings, Help is coming`) into the game
  chat input, then presses send.
- If another admin offers you a **handshake**, the bot clicks *Accept/Confirm*
  after a random human-like delay (2–6 s default) so you pass the AFK check.
- A **floating overlay panel** shows live status: reports answered, handshakes
  accepted, last command — with Pause/Resume and Copy-last-command buttons.

## Built-in replies

| Report contains | Bot reply |
|---|---|
| help / admin / generic | Greetings, Help is coming |
| car stuck / flipped / in water | Greetings, Use towtruck option. |
| petrol / gas / fuel empty | Greetings, We don't provide that such services. |
| change my skin | Greetings, We don't provide that such services. |
| rp or nrp name question | Auto verdict: *Byron_Vance is a valid RP name* |
| scam / money lost | Greetings, Make a report on the forum with proof. |
| dm / killed me | Greetings, We are watching, send proof on the forum. |
| unban / ban appeal | Greetings, Make an appeal on the forum. |
| thanks | Greetings, You have been helped. Enjoy the game! |

17 rules ship by default — you can import your own rules JSON
(generated by the web dashboard's **Rules → Export JSON** button).

## Setup

1. Install the APK (allow install from unknown sources).
2. Open **GrandRP ReportBot** → *Enable accessibility service* → turn on
   "GrandRP Report Bot".
3. *Grant overlay permission* → *Show floating panel*.
4. Adjust the **Reply command** to the command your server uses for
   answering reports (default `/ans {id} {message}` — some servers use `/re`).
5. Open Grand RP Mobile and go to sleep 😴

## Build

GitHub Actions builds the signed release APK automatically on every push to
`main` (see `.github/workflows/build.yml`). The APK is attached to the
[Releases](../../releases) page and uploaded as a build artifact.

Local build: `gradle assembleRelease` (JDK 17).
